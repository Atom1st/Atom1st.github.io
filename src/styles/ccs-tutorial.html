01

设计令牌

所有颜色、间距、圆角都写在 :root 的变量里。想换皮肤，改变量即可——下面四个旋钮真的会改变整页的主色。

实时演示

这是一张卡片

左色条、徽章、按钮都吃 --accent 这一个变量。

chip badge 
/* 换主色：只覆盖变量，不动任何组件规则 */
:root {
  --accent: #1A7F37;
  --accent-strong: #116329;
  --accent-soft: rgba(26, 127, 55, .10);
  --accent-line: rgba(26, 127, 55, .35);
}

/* 想更硬朗 / 更柔和，也只是一个变量 */
:root { --radius-sm: 0px; --bar: 6px; }
试一试 →把圆角拖到 12px，你会发现整套设计开始「松」掉——这正是直角 2px 是刻意选择的原因。

分类色

这是 CCS 最值得学的一个机制：.cat-* 只定义两个局部变量，加在任何容器上，里面的 .chip 和卡片左色条都会跟着变色。

实时演示

记录

记录·cat-blue

文学

文学·cat-purple

理论

理论·cat-teal

学习

学习·cat-orange
切换后观察演示区第一张卡的左色条与 chip 
/* .cat-* 只做两件事：定义 --cat 与 --cat-soft */
.cat-blue { --cat: #0969DA; --cat-soft: rgba(9,105,218,.12); }

/* 于是这两处无需写颜色，自动继承 */
.card[class*="cat-"] { border-left-color: var(--cat); }
.chip { color: var(--cat); background: var(--cat-soft); }

/* 用的时候：容器加类即可 */
<a class="card cat-teal" href="#">
  <span class="chip">理论</span>
</a>
试一试 →把 .cat-teal 加到一个外层 div 上，里面的所有 .chip 会一起变青——变量是继承的。

为什么要自己写一套 CSS

因为每写一个新页面，你都在重复实现同一套按钮、卡片、提示框。把决定过一次的事情写进变量，之后只做「组合」。

组合优于复制

一个分类列表页可以完全由 .filters + .card-list + .card.cat-* 拼出来，不写一行新 CSS。

13

零类名兜底

到目前为止，每个演示都加了类。如果你写一段一个 class 都没有的 HTML —— 比如随手做的练习页 —— 会看到什么？ 答案是：只剩 body、h1~h6、p、a 这些标签级规则在工作， 输入框和按钮全是浏览器原生的样子。那不是没加载成功，而是组件样式本来就要靠类触发。

旧版的两个坑（已在 ccs.css 修好）
为什么裸 input 没样式
/* 坑 1：只列举具体 type，裸 input 匹配不到 */
input[type="text"], input[type="number"] { … }
/* <input id="a" name="a"> 没有 type 属性
   → 等价于 text，但选择器写的是 [type="text"]，匹配失败 */

/* 修复：改成「排除法」，裸 input 也会落进来 */
:where(input:not([type="checkbox"]):not([type="radio"])
        :not([type="submit"]):not([type="hidden"]), select, textarea) { … }

/* 坑 2：<input type="submit"> 不属于 .btn 体系，保持原生灰按钮
   修复：第 17 节给它和裸 <button> 补了与 .btn 一致的外观 */
现在：零类名也体面

ccs.css 第 17 节给裸标签补了一层默认呈现。下面这块演示区里的每个元素都没有 class：

零 class 实时演示

A + B 计算器

标题、段落、标签、输入框、提交按钮、结果框，全部裸标签。

结果：—

<form>
  <label for="a">A</label>
  <input id="a" name="a" inputmode="decimal">

  <label for="b">B</label>
  <input id="b" name="b" inputmode="decimal">

  <input type="submit" value="计算 A + B">

<p>结果：<output id="sum">—</output></p>
试一试 → 在演示里填两个小数相加（比如 0.1 和 0.2），结果是 0.3 而不是 0.30000000000000004 —— 演示脚本按小数位放大成整数再相加。
兜底覆盖清单
裸标签兜底后
body > form白底卡片 + 左侧主色条 + 内边距，760px 居中
无 class 的 label块级、14px 加粗
无 class 的 input / select / textarea白底、1px 描边、2px 圆角、占满整行
input[type=submit]主色实心（等同 .btn）
input[type=button|reset] / 裸 button描边按钮（等同 .btn-outline）
output主色浅底徽章
fieldset / legend带边框分组 + 分组标题
注意：兜底只作用于「无 class」的元素和 body 的直接子级。 一旦你加了 .page / .btn 等类，就完全交给组件规则，两者不会打架。 不想要这层兜底，删掉 ccs.css 第 17 节整段即可。
