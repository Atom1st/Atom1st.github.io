    GitHub 仓库（博客自持图床）

    图片提交到 owner/repo 的 public/uploads/，Actions 部署后直链 https://站点/uploads/…。Token 需要 repo 权限，在 GitHub → Settings → Developer settings → Personal access tokens 生成。

    ImgBB（imgbb.com）

    imgbb.com 邮箱注册 → api.imgbb.com 点 Get API key 即得。国内直连，无需翻墙。

    picgo.net（Chevereto）

    www.picgo.net 邮箱注册 → 右上角设置 → API → 重新生成密钥。单图 ≤ 25MB。
