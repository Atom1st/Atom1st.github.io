# Studio · 本地写作工作台

一个跑在本机的单页写作工具，专为这个 Astro 博客做的：左边管文章、中间写 Markdown、右边改属性，写完点一下「一键发布」就 build + 推到 GitHub。除了管网站，还带一套轻量的写作习惯机制——每日目标、连续天数、专注冲刺、随机草稿、到点提醒。

- 写作本体不联网、不上传；只有主动用「图床」时才请求蜜蜂图床
- 数据就是你仓库里的 `src/content/posts/*.md`，没有第二份副本
- 编辑器是 Vditor（本地离线副本，放在 `vendor/`），支持所见即所得 / 分屏 / 源码三种模式

## 启动

双击 `tools/studio/start.cmd`，浏览器会自动打开 <http://127.0.0.1:7788>。

命令行方式：

```bash
node tools/studio/server.mjs
# 指定端口
STUDIO_PORT=8090 node tools/studio/server.mjs
```

首次启动如果缺 `node_modules`，`start.cmd` 会自动跑 `bun install`。

## 能干什么

### 管文章

| 区域 | 功能 |
| --- | --- |
| 左栏 · 文章 | 按分类筛选、全文搜索、新建文章、文章标记（加密 / 热门 / PDF / 资源 / 页面 / 今天） |
| 左栏 · 今日 | 今日字数圆环、连续天数、近 30 天达标率、7 天柱状、专注时长、每日目标与提醒 |
| 左栏 · 草稿箱 | 随手记碎片想法，之后再「发成文章」 |
| 中间 | Vditor 编辑器，Markdown 正文，图片直接拖进来会存到 `public/uploads/YYYYMM/` |
| 右栏 · 属性 | 标题 / slug / 日期 / 分类 / 类型 / 来源 / 访问权限 + 密码 / 摘要 / PDF / 热门 / 选题标签 |
| 右栏 · 发布 | 一键发布、单独生成索引、单独 build、git 状态 / 日志 / pull |

一键发布的完整流程：

1. 保存当前 md
2. `bun run encrypt` —— 重新生成 `src/data/articles.json`，并加密受保护文章
3. `bun run build` —— 先验证站点能编译，编不过就不提交
4. `git add -A` → `git commit` → `git push origin <branch>`
5. GitHub Actions 自动部署，1–2 分钟后上线

日志实时滚动在下方抽屉里，任何一步失败会立刻中断并停在那一步。

### 图床

右栏「图床」Tab 接的是[蜜蜂图床](https://www.beeimg.cn)。填入你自己的 API Token 后点「保存配置」，Token 只写在本机 `tools/studio/.studio.json`，不进文章、不回传明文，重新打开也不会显示原文。

- 点选或拖入图片（可多选），上传完直接拿到直链
- 每条结果可「复制链接」「复制 MD」，或「插入正文」写进当前文章
- 「测试连接」检查接口是否可达；若 Token 没生效会提示当前按游客身份上传
- API 地址默认 `https://www.beeimg.cn`，自建站可改；`storage_id` 由后端自动获取
- 编辑器自带的图片上传仍是本地 `public/uploads/`，和这里互不干扰

### 养写作习惯

**每日目标 + 连续天数**
今日面板里设定每天写多少字（默认 500）。达到目标即算打卡一天，底部状态栏一直显示「🔥 连续 N 天」。连续有 **7 天宽限**：断更不超过 6 天，再动笔就接着算，不会清零。

**写作热力图**
今日面板的格子图，一眼看清这半年你在哪天写了、什么时候写的：

- **颜色**（色相）= 当天写得最多的时段：上午蓝、下午绿、晚上橙、凌晨紫
- **深浅** = 当天字数多少：过半、达标、翻倍逐级加深，悬停看具体数字和专注时长

**写作冲刺**
点右上角「专注」（或 `Ctrl+Shift+F`）进入专注模式：两侧栏收起、正文居中加宽，底部出现冲刺进度条，目标是每日目标的三分之一。专注期间每 30 秒自动保存一次。

**草稿箱**
没有标题、不想选分类的碎片，先扔进草稿箱。**草稿里打的字计入每日字数**（净增量），和正文一起攒进度。从文章转存草稿不重复计分。草稿弹窗里打字会自动保存，存够了点「发成文章」直接转成正式 md。

**每日提醒**
开启后，到点（默认 21:00）如果今天没写够，Studio 会弹一条 Windows 系统通知。前提是 Studio 进程还开着。

**选题标签**
右栏可以给文章打本地标签（比如「待写」「系列」「教程」），只存浏览器 localStorage，不会写进 md，也不影响发布。

字数怎么算：只统计「真的敲键盘」产生的净增量，删字会扣——正文和草稿箱都算。切换文章、外部改了文件导致的字数变化不会算进今日。专注时长只统计专注模式下、且 5 分钟内有输入的时间。热力图的时段分区按写字那一刻的钟点归入凌晨（0-6）／上午（6-12）／下午（12-18）／晚上（18-24）。

## 几个约定

- **slug 就是文件名**，线上地址是 `/articles/<slug>`；改名会自动搬 `public/encrypted/<slug>.json`。
- **受保护文章**：`access: protected` + 填密码，密码明文写在本地 md 里（这类文件已被 `.gitignore` 排除），发布时正文会被 AES-GCM 加密到 `public/encrypted/`。
- **新建文章一定要走一遍「生成索引」**，否则 `articles.json` 里没有它，列表页就不会显示。一键发布会自动做。
- 编辑器里的 Markdown 就是博客正文，公式 `$…$` / `$$…$$` / `\(…\)` / `\[…]` 都支持。
- **LaTeX 方括号公式**：源文件保持 `\(…\)` / `\[…]` 写法（与博客 remark 插件一致），编辑器内会自动显示为 `$…$` / `$$…$$` 并正常渲染公式；保存时自动还原成方括号写法。转换逻辑在 `public/math-adapter.js`。
- **保存是无损的**：日期沿用你原来的写法（`2026-9-11` 不会被改成 `2026-09-11`），原有 frontmatter 字段（包括作者自己加的）原样保留，结尾有没有换行也照旧。内容没变化时根本不碰文件。

## 数据在哪

| 文件 | 内容 | 会提交吗 |
| --- | --- | --- |
| `src/content/posts/*.md` | 文章源文件 | 会（受保护的除外） |
| `tools/studio/.studio.json` | 发布偏好 + 图床 Token（本机明文） | 不会 |
| `tools/studio/.studio-habit.json` | 写作习惯统计（每日字数 / 专注 / 连续天数） | 不会 |
| `tools/studio/drafts/*.json` | 草稿箱 | 不会 |
| 浏览器 localStorage | 明暗主题、选题标签、上次打开的文章 | — |

想从零开始一轮新的坚持，删掉 `.studio-habit.json` 就行。

## 目录

```
tools/studio/
├─ server.mjs          HTTP 服务 + 文件操作 + 命令执行（零依赖，只用 node 内置模块）
├─ public/             WebUI（index.html / app.css / app.js）
├─ vendor/dist/        Vditor 3.11.3 离线资源
├─ start.cmd           Windows 启动器
└─ .studio.json        本地偏好，已 gitignore
```

## 注意

- 服务只监听 `127.0.0.1`，不会暴露到局域网。
- 「本地预览」按钮会另起一个 `astro dev`（默认 4321），按 `Ctrl+C` 退出 Studio 时会一并关掉它；直接关窗口则可能残留，需要到任务管理器结束 `node`。
- 发布用的是本机 git 凭据，和你平时在终端 `git push` 完全一样。
- 每日提醒依赖 Windows 通知中心；如果系统关掉了通知权限，会退化成托盘气泡，再不行就静默失败（不影响写作）。
