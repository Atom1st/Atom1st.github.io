      专注模式
      
          
        
            
      • 隐藏两侧栏，只留正文，进入后底部出现「写作冲刺」进度条。
        • 
            
      • 冲刺目标是 每日目标 ÷ 3，随时可手动结束。
        • 
            
      • 专注期间每 30 秒自动存一次，断电也不丢。
        • 
          
      
        
      
        
      
          
      习惯怎么算
      
          
        
            
      • 字数按「净增量」累计：删字会扣，避免刷字数。草稿箱里写的字同样计入每日（算「草稿」区）。
        • 
            
      • 连续天数有 7 天宽限：断更不超过 6 天，补写后就接着算，不会清零。
        • 
            
      • 热力图（约一个月）：格子颜色 = 当天写得最多的分类（记录蓝 / 文学紫 / 理论青 / 学习绿 / 生活橙 / 评论红 / 草稿灰），颜色深浅 = 当天字数多少。左侧标星期，列头标日期，黑框是今天。悬停看详情。
        • 
            
      • 专注时长只统计专注模式下、且 5 分钟内有输入的时间。
        • 
            
      • 数据存在 tools/studio/.studio-habit.json，不同步、不上传。
        • 
          
      
        
      
        
      
          
      草稿箱
      
          
        
            
      • 碎片想法先扔进草稿箱，不用先想标题和文件名。
        • 
            
      • 草稿里打的字计入每日字数；从文章转存草稿不重复计。
        • 
            
      • 草稿点「发成文章」时才选分类、生成 md。
        • 
            
      • 草稿存在 tools/studio/drafts/。
        • 
          
      
        
      
        
      
          
      写作用法
      
          
        
            
      • 正文即 src/content/posts/*.md 的 body，直接写 Markdown。
        • 
            
      • 公式 $…$ / $$…$$ 编辑期内联渲染，保存时自动转回 \(…\) / \[…]。
        • 
            
      • 图片可直接拖进编辑器，自动存到 public/uploads/YYYYMM/。
        • 
          
      
        
      
        
      
          
      发布做了什么
      
          
        
            
      1. 保存当前 md
        2. 
            
      2. 运行 encrypt 脚本，重新生成 src/data/articles.json，并加密受保护文章
        3. 
            
      3. astro build 验证站点能编译
        4. 
            
      4. git add / commit / push，GitHub Actions 自动部署
        5.
